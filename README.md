## 📌 About the Project

In today's digital world, people own numerous digital assets, including social media accounts, email accounts, cloud storage, subscriptions, photographs, and personal memories.

However, most people do not have a proper plan for managing these digital assets in the event of prolonged inactivity or their absence.

**Memory Vault** is a Digital Legacy Management System designed to help individuals organize their digital presence, record their final wishes, nominate trusted contacts, and preserve important memories.

It provides a centralized platform where users can manage their digital assets and plan how their digital legacy should be handled responsibly.

## ✨ Key Features

- **User Authentication:** Register and log in to a personal account.
- **Digital Asset Management:** Add, organize, edit, and manage digital assets such as Instagram, Facebook, Gmail, Google Drive, and subscriptions.
- **Final Wishes:** Specify instructions for individual digital assets.
- **Trusted Contacts:** Nominate trusted individuals and manage their contact information.
- **Memories & Letters:** Save personal memories and meaningful messages for intended recipients.
- **Inactivity Monitoring:** Demonstrate inactivity-based reminders and notification stages.
- **Legacy Access Requests:** Allow trusted contacts to submit legacy access requests.
- **Admin Dashboard:** Review and manage legacy access requests.
- **Legacy Summary:** View a consolidated summary of digital assets, final wishes, contacts, and memories.

## ⚙️ How It Works

1. **Register:** Create your personal Memory Vault account.
2. **Add Digital Assets:** List your important online accounts and digital assets.
3. **Set Final Wishes:** Specify what should happen to each asset.
4. **Add Trusted Contacts:** Nominate people who may be contacted when necessary.
5. **Preserve Memories:** Save personal letters and meaningful messages.
6. **Monitor Inactivity:** Use the inactivity workflow to demonstrate reminder stages.
7. **Manage Legacy Requests:** Review access requests through the administrative workflow.

## 💾 Data Storage

Memory Vault currently uses the browser's **Local Storage** to save application data.

- Data is stored locally in the user's browser.
- Data persists across page refreshes in the same browser.
- No external database is required for the current demonstration.
- Data is not automatically synchronized across devices or browsers.
- Clearing browser storage may permanently remove saved application data.

**Note:** Local Storage is suitable for a prototype and demonstration, but it is not a secure production database for sensitive personal information.

## 💻 Run Locally

### Prerequisites
- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project directory:

   ```bash
   cd memory-vault
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

*Note: These commands assume your repository includes a compatible `package.json` and development script.*

## 🔒 Privacy & Security Considerations

- The current version uses browser Local Storage.
- Do not store actual third-party account passwords.
- Avoid entering sensitive personal information into the demonstration.
- Inactivity alone must never be treated as proof of death.
- Legacy access should require appropriate authorization and review.
